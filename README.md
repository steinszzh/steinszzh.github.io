## What this repo is

This resume is itself a work sample. It was spec'd and built with a multi-agent
AI pipeline (planner → designer → content → review), then human-reviewed and
deployed as a static site — no build step, no framework.

```
index.html   structure & content (EN/中 bilingual via data-i18n)
style.css    editorial-tech design system, print-optimized
main.js      i18n, scroll reveal, Chart.js radar, PDF/print
```

## Deploy

1. Push these three files (plus this README) to a repo named `<username>.github.io`, or any repo.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Done — updates go live on every push.
